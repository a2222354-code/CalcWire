AWG калькулятор: проект Android Studio

Как получить APK
1. Установи Android Studio (бесплатно, developer.android.com/studio).
2. File, Open, выбери папку AwgCalc. Дождись окончания Gradle Sync
   (при первом запуске скачаются Gradle 8.7 и компоненты Android, нужен интернет).
3. Для проверки на телефоне: включи отладку по USB и нажми Run.
4. Для APK: Build, Build Bundle(s) / APK(s), Build APK(s).
   Готовый файл: app/build/outputs/apk/debug/app-debug.apk
   Скопируй его на телефон и открой. Если Android спросит, разреши установку из этого источника.

Как изменить расчёт
Вся логика и интерфейс лежат в app/src/main/assets/index.html.
Тот же файл можно открыть в браузере телефона без сборки APK.

Иконка приложения стандартная (системная). Свою иконку можно добавить через
File, New, Image Asset.

Сборка APK онлайн (без Android Studio)
1. Создай аккаунт на https://github.com/ и новый пустой репозиторий.
2. Распакуй архив и загрузи в корень репозитория всё содержимое папки AwgCalc,
   включая скрытую папку .github. Удобно: Add file -> Upload files.
3. Открой вкладку Actions. Если GitHub попросит разрешить Actions, подтверди.
4. После загрузки файлов workflow обычно запустится автоматически. Также его
   можно запустить вручную: Actions -> Build Android APK -> Run workflow.
5. Дождись зелёного статуса завершения сборки. Открой завершённый запуск и
   внизу страницы Artifacts скачай AwgCalc-debug-apk.
6. Распакуй скачанный архив: внутри будет app-debug.apk.

Это debug APK для установки и проверки. Для публикации в Google Play или
распространения как релизной версии потребуется отдельная release-сборка
с подписью собственным ключом.
